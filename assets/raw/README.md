# AI로 만든 그림 올리는 곳

`../AI_그림_프롬프트.md`의 프롬프트로 만든 그림을 이 폴더에 올려 주세요.

- 파일 이름은 목록에 적힌 이름 그대로 (예: `heroine1_meet.png`). 확장자는 png·jpg 모두 괜찮습니다.
- 올리는 법: GitHub에서 이 폴더(`assets/raw`)를 연 뒤 **Add file → Upload files** → 그림을 끌어다 놓기 → **Commit changes**
- 몇 장씩 나눠 올려도 됩니다. 올린 뒤 알려 주시면 배경을 지우고 크기를 맞춰 `images/`에 넣습니다.
