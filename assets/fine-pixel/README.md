# 작은 픽셀 인물 그림

사용자가 승인한 `../semirealistic/concepts/hana-fine-pixel.png`의 작은 픽셀 질감과 귀여운 비율을 기준으로 게임 인물 65장을 교체했습니다.

- 주인공 10단계 × 외모 3종 = 30장
- 히로인 6명 × 만남·연인·결혼식·배우자 = 24장
- 조연 11장 (부모님은 두 인물이 함께 등장하는 한 장)
- 게임 파일: `../../images/이름.png`, 1024×1536 투명 PNG
- 전체 미리보기: `index.html` (게임에 연결된 파일을 직접 사용)

내장 이미지 생성 도구로 각 그림을 별도 제작했습니다. 윤하나 만남은 승인된 콘셉트를 그대로 사용했습니다. 기존 인물 그림을 변환하지 않고 글로 정리한 특징을 바탕으로 새로 그렸으며, 동일 인물의 다른 단계에는 이번에 새로 제작한 기본 얼굴을 참고했습니다. 배경 그림은 이번 교체 대상에 포함하지 않았습니다.

`manifest.json`은 65장의 제작 명세, `progress.json`은 실제 생성 프롬프트·참고 그림·저장 경로 기록입니다. 릴리는 성인 미국인 배우로 금발·파란 눈·보조개 없는 부드러운 미소를 유지했습니다.

교체 전 인물 파일은 Git 커밋 `c0b126b`에 남아 있습니다. 반실사와 다른 픽셀 콘셉트는 `../semirealistic/`에 별도 보존했습니다. 새 그림을 추가할 때 같은 파일명과 2:3 비율을 유지하세요. 픽셀 표시는 저장 해상도에 관계없이 적용됩니다.
