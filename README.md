# baseball-life — 야구 인생 카드

한국 야구 선수의 일생을 카드로 플레이하는 웹 게임입니다.
초등학교 → 중학교 → 고등학교 → 신인 드래프트 → (대학) → 프로 → (메이저리그) → 은퇴까지,
시기마다 나오는 카드의 선택지로 능력치·행복도·연애가 바뀌고, 은퇴하면 성적과 행복도로 엔딩이 정해집니다.

## 실행

- PC: `index.html`을 더블클릭 (빌드·설치 없음)
- 휴대폰: GitHub Pages로 공개한 뒤 링크로 접속 → `안내서.md` 6장

## 고치기

카드·히로인·엔딩·규칙 숫자는 모두 `data` 폴더에 있습니다. 쓰는 법은 **[안내서.md](안내서.md)** 를 보세요.
일러스트는 `images` 폴더에 넣습니다 (`images/README.md`).

## 저장 이동과 연습

시작 화면 또는 게임 메뉴의 **저장 이동·복구**에서 경력·선수 수첩·도감·다음 인생 보너스를 JSON 파일로 옮길 수 있습니다. 가져오기는 내용을 미리 본 뒤 덮어쓰기를 확인해야 적용되며, 직전 저장은 복구 사본으로 남습니다. 효과음·움직임 설정은 기기별로 유지됩니다.

자유행동의 **연습**에서는 포지션에 맞는 능력치를 직접 골라 +1 올립니다. 돌아가기는 자유시간을 소비하지 않습니다. **미니게임 연습장**은 기존처럼 보상이나 본게임 상태 변경 없이 조작을 익히는 곳입니다.

검증 명령과 호환성: [편의성 개선 기록](docs/QUALITY-OF-LIFE.md).

결과 카드에는 성장·회복·정산까지 포함한 실제 전후 변화와 상한 적용을 표시합니다. 본게임의 첫 종목은 조작 안내를 읽고 준비 완료 후 시작하며, 같은 접속의 반복 승부는 바로 진행합니다. 선수 수첩에서는 실제 콜업·계약 조건의 충족 상태를 확인할 수 있습니다(출전·다음 사건 확정 안내는 아닙니다).
